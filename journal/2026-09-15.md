# 2026-09-15 — gram-gatherer

## Goals for the day

Turn a pile of saved Instagram posts (recipes, books, albums, workouts, and the rest) into searchable text so they are faster to find than reels, and so the same item does not get saved twice.

Ship it as a Cursor skill first: paste one Instagram URL, extract what matters, write one markdown file. Leave room for Twos, an app, and an iPhone Shortcut later.

## Tasks completed

- Stood up the repo as a skill plus Python CLI (`scripts/gather.py`). Paste one URL; get one file under `library/`.
- Caption is the first content check. If the caption already names the books, album, recipe, or workout, stop. No download, OCR, or Whisper.
- If the caption is thin, fetch media: Whisper for reels, carousel slides for swipe-for-the-list posts. `"Swipe for the list"` no longer counts as a complete caption.
- Dedup by Instagram shortcode in `library/index.json`.
- Typed folders: `library/books/`, `library/albums/`, `library/workouts/`, `library/recipes/`, `library/other/`.
- Cache is a scratch pad only. After a successful save, `cache/<shortcode>/` is deleted so videos and slides do not pile up.
- Installed Whisper on this machine, not only this repo: user Python `faster-whisper`, ffmpeg on PATH, and a `transcribe` command from any folder. New terminals (or a Cursor restart) pick up PATH.

## Tests made

Three book edge cases, then a workout, then albums:

1. **Caption already had the list** — [JoshReadsBooks reel](https://www.instagram.com/reel/DPyoYlngK01/). Five titles in the caption. Saved as a book without watching the video.
2. **Useful bit in the audio** — [Nathan Shuherk niche nonfiction](https://www.instagram.com/reel/C77h593vthE/). Caption was only a vibe line. Whisper transcribed six titles. One miss we corrected by hand: *Against Technoableism*, not “Technoableism”.
3. **Useful bit on the slides** — [Texan by Nature carousel](https://www.instagram.com/p/Dc8ozlamwzs/). Caption said swipe. Titles were on 15 slides. Image carousels have no video; we pull slide thumbnails and read them.
4. **Workout** — [John Noel / INEIJMA](https://www.instagram.com/reel/DWl3omsEaft/). Full circuit was in the caption. Landed in `other/` first; then we added `library/workouts/` and moved it.
5. **Albums** — [Don Chenz six new albums](https://www.instagram.com/reel/DQ7-t-ajNPl/). Caption was the hook; Whisper named the six records. Feature spellings from audio can be fuzzy, same class of miss as the technoableism title.

Library so far: three book files, one workout, one album list. Index is `library/index.json`.
