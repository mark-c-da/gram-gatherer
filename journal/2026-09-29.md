## Goals for the day

Get the text that lives on the picture, not only in the caption or the audio. Carousel slides and silent reels were the hole: titles on screen, nothing useful in the caption, Whisper with nothing to hear.

Keep Twos as the inbox. The MCP drain path is the one we use at the desk. Fold the REST workflow into the same branch so both shells share URL extraction.

## Tasks completed

- **Carousel OCR is gated.** Tesseract runs only on image carousels: 2+ stills and no video. Reel thumbnails and a lone oEmbed image no longer get OCR'd.
- **HEIC slides.** Instagram carousel thumbs often arrive as `.heic` / `.heif`. `pillow-heif` treats them as images.
- **Silent reel frame OCR.** If the caption is thin and Whisper comes back empty, sample frames across the video length (up to 12), OCR them (`ocr-frames`), and copy the JPEGs to `archive/frames/<shortcode>/` so we can check whether the sample hit the titles. `cache/` still clears after a successful save. Frame OCR is skipped when Whisper already has the list.
- **Twos paths share one core.** Merged REST Workflow 1 (`--from-twos` / `--to-twos`) into the MCP branch. URL extraction lives in one place for the file adapter and the Twos adapter. MCP stays the desk path (list → URL file → library → dated Twos list). REST is the headless shell when there is a `TWOS_API_KEY` and no Cursor in the loop.
- README and `docs/PATHS.md` diagrams now show caption → carousel OCR → Whisper → frame OCR, and both Twos shells.
